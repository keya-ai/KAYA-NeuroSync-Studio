KAYA-NeuroSync Studio is an edge-native, offline Brain-Computer Interface (BCI) engineered to restore communication and emergency agency for locked-in and severely motor-impaired individuals.  Powered by the dual-processor Arduino UNO Q (STM32U585 MCU running Zephyr RTOS paired with a Qualcomm Dragonwing QRB2210 MPU executing Debian Linux), the system captures single-channel biopotentials via a BioAmp EXG module. It extracts EOG horizontal eye movements for smooth navigation across an 8-option clinical grid and detects EMG masseter jaw clenches for zero-latency priority emergency alerts. All signal conditioning, feature extraction, and Scikit-Learn Random Forest ML inference run 100% locally on-device without cloud dependencies.  Key FeaturesDual-Processor Partitioning: Microsecond 14-bit 250 Hz ADC sampling and 50 Hz IIR notch filtering on Zephyr RTOS; feature extraction and ML classification on Debian Linux.  Zero-Allocation RPC Bridge: 10 Hz batched memory dispatches (std::array<float, 25>) across Arduino_RouterBridge to minimize CPU interrupts.  On-Device Edge ML: Onboard Scikit-Learn RandomForestClassifier with incremental training and persistent local eMMC storage (/python/data/).  Clinical HDMI UI: Futuristic dark-mode HTML5 Canvas dashboard rendered via Arduino App Lab's WebUI Brick.  High Reliability: Sub-18.5 ms emergency trigger response time and 96.5% overall classification accuracy.
